## Решения при реализации

1. Работа в согласованной текущей ветке с переименованием без нового worktree.
   Цена ошибки изоляции — изменения в пользовательском checkout; посторонние
   untracked-документы сохранены и исключены из коммитов.
2. Требование пользователя: отдельная Astra после каждого этапа и повторное ревью
   исправлений, вместо одного финального ревью из executing-plans. Цена — время.
3. Неработающие Git Bash helpers заменены Python/PowerShell с тем же ledger/brief.
   На поведение продукта не влияет; цена — сопровождение временных helpers.
4. CAS и generation fencing расширены на context уже в этапе3 для атомарной
   смены размера. Цена совместимости — согласованное обновление клиента и сервера.
5. Preview получил отдельный RedisChannelLayer, чтобы worker рассылал в браузер.
   Production не изменён; цена — Redis нужен для такого preview.
6. hash_updates в общей транзакции сохраняют lastAppliedAt вместе с бонусом
   и дедупликацией. Цена — более широкий контракт storage, покрытый гонками.
7. Смена binding/повторный JOIN после PART открывает новый IRC stream; общий marker
   lease защищает startup-status. Цена — краткое переподключение остальных каналов
   этого worker, зато старый ACK не подтверждает новую привязку.
