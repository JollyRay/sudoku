# Sudoku: функциональный контракт для новой версии

Этот документ фиксирует только пользовательские возможности существующего
компонента Sudoku. Его структура кода, DOM-разметка, названия внутренних
функций и формат старых сообщений не являются контрактом для `sudoku-vibe`.

## Вход и лобби

- Пользователь входит в лобби по имени и коду комнаты.
- Имя пользователя сохраняется в cookie, а код комнаты — в сессии.
- Страница игры доступна только при наличии имени и комнаты; иначе
  пользователь возвращается к форме входа.
- В одном лобби имя пользователя должно быть уникальным.

## Игровые доски

- Основная доска Sudoku имеет размер 9×9 и состоит из 81 адресуемой ячейки.
- У каждого пользователя есть собственная доска, подписанная его именем.
- Пользователь видит свою доску и доски остальных участников лобби.
- При подключении восстанавливается актуальное состояние всех досок комнаты.
- При подключении, отключении и повторном подключении состав отображаемых
  участников синхронизируется в реальном времени.

## Создание и состояние игры

- Пользователь может запросить новую доску выбранной сложности.
- Доска выбирается из сохранённых вариантов и содержит исходные неизменяемые
  значения и пустые ячейки.
- Для одной партии хранятся текущие значения ячеек, исходные значения,
  ошибочные ответы, время начала, время завершения и связанные с ячейками
  бонусы.
- Повторная загрузка страницы не должна терять актуальное состояние партии.
- Завершённая доска помечается как решённая.

## Работа с ячейками

- Пользователь может выбрать изменяемую ячейку и установить или очистить её
  значение.
- Допустимые игровые значения — цифры от 1 до 9 и пустое значение.
- Сервер проверяет введённое значение и хранит авторитетное состояние доски.
- Результат хода видят остальные участники лобби.
- Интерфейс умеет выделять выбранную ячейку, ячейки с тем же значением и,
  по выбору пользователя, ошибочные ответы.
- Поддерживаются заметки-кандидаты, ввод сначала ячейки или сначала цифры и
  ввод с клавиатуры либо экранной цифровой панели.

## Прогресс

- Для каждого участника отображается количество заполненных ячеек.
- Для активной партии отображается таймер от начала решения.
- Время завершения фиксируется один раз после правильного заполнения доски.

## Представление

- Пользователь может переключать визуальное представление значений, не меняя
  игровое состояние.
- Доски соперников можно выбирать для просмотра.

## События и бонусы

- Бонус может быть связан с ячейкой и срабатывает при её правильном заполнении.
- Существующие типы эффектов: перестановка строк или столбцов, временное
  скрытие блока, вращение блока и анимация блока.
- Событие адресуется конкретной доске, нескольким доскам или всему лобби.
- Внешний доверенный источник может инициировать бонусное событие.
- Существующая интеграция с Twitch позволяет владельцу подключить свой канал
  и получать подтверждение успешного подключения.

## Границы новой реализации

В `sudoku-vibe` необходимо сохранить перечисленное поведение по мере
реализации соответствующих этапов, но не следует переносить:

- зависимость разметки от абсолютных координат и визуальных размеров;
- объединение сетевого протокола, состояния, DOM-операций и эффектов в одном
  файле;
- старые имена сообщений и размещение полей рядом с `kind`;
- хранение оперативного состояния лобби только в реляционных моделях;
- доверие к присланным клиентом признакам завершения игры;
- жёсткую привязку ядра доски к конкретным темам оформления или бонусам.

Новая версия должна разделять статичную разметку, конфигурацию, очередь
событий, библиотечные операции над доской, WebSocket-транспорт, обработчики
событий и серверное состояние лобби.
